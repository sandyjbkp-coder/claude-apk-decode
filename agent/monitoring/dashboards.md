## Dashboard Rendering

Each dashboard is generated by reading metrics from `agent/logs/metrics.jsonl`
and formatting as text. Run `agent-status` to see a summary view.

## Dashboard Refresh

- Auto-refreshed on every `agent-status` invocation
- Can be generated standalone by parsing metrics.jsonl
